# input/videos/

Copia aquí vídeos **locales** (.mp4, .mov, .mkv, .webm, .avi).

Cuándo usar esta carpeta en vez de una URL de YouTube:

- el vídeo es privado o no listado en YouTube;
- es material propio sin publicar;
- es de otra plataforma.

Si el vídeo **está público en YouTube**, no lo descargues: pon la URL en
`input/REFERENCIAS.md`. Gemini lo analiza directamente y es más rápido,
más barato y más limpio.

Los vídeos locales se suben temporalmente a la Files API de Google para
analizarlos y el propio servicio los borra a las pocas horas.

Nada de lo que pongas aquí se sube a Git.
