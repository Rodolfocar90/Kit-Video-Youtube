# input/channel-context/

Aquí va el contexto de tu canal. Se rellena una vez y sirve para siempre.

1. Copia `canal.example.md` como `canal.md` y rellénalo.
2. Si quieres, añade más archivos `.md`: análisis de competencia, tu
   posicionamiento, lista de temas pendientes, feedback de tu audiencia.

Todos los `.md` de esta carpeta se leen al preparar un vídeo.
Solo `canal.example.md` se sube a Git; el resto no.
